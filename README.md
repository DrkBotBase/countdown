# 🎬 Countdown App - Versión Ficticia

Una aplicación web progresiva (PWA) inspirada en la película "Countdown", que predice de forma aleatoria y ficticia tu fecha de "muerte".

## 🚀 Características

- ✅ PWA completa (instalable en dispositivos)
- ✅ Tema cscuro
- ✅ Countdown en tiempo real
- ✅ Causas de muerte aleatorias con humor negro
- ✅ Términos y condiciones ficticios
- ✅ Totalmente responsive

## 🛠️ Tecnologías

- Node.js
- Express.js
- EJS (templates)
- JavaScript Vanilla
- CSS3
- Service Workers

## 📦 Instalación

```bash
git clone [tu-repositorio]
cd countdown-app
npm install
npm run dev
